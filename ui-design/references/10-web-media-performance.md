# 10. Веб: медиа, производительность, мета-изображения, alt

Источники: web.dev (Core Web Vitals, LCP, CLS, fetchpriority, lazy-loading, AVIF), MDN (responsive images), W3C WAI (alt decision tree, pause-stop-hide), Evil Martians (favicons), Front-End Checklist.

## Core Web Vitals

Оцениваются по 75-му перцентилю реальных пользователей, отдельно мобильные и десктоп.

| Метрика | Хорошо | Плохо |
|---|---|---|
| LCP (крупнейший элемент) | ≤ 2,5 с | > 4 с |
| INP (отзывчивость) | ≤ 200 мс | > 500 мс |
| CLS (сдвиги вёрстки) | ≤ 0,1 | > 0,25 |

Дизайн влияет на все три: тяжёлый герой → LCP; тяжёлые эффекты и анимации → INP; баннеры, шрифты и картинки без размеров → CLS.

## Адаптивные изображения

```html
<img src="hero-1600.jpg"
     srcset="hero-800.avif 800w, hero-1600.avif 1600w, hero-2400.avif 2400w"
     sizes="(width < 768px) 100vw, 50vw"
     width="1600" height="900"
     fetchpriority="high" alt="…">
```

- В `srcset` — ширины в `w`. В `sizes` — `vw` или px (не %), первое подходящее условие выигрывает, значение по умолчанию последним.
- `<picture>` нужен только для смены кропа (арт-дирекшн) или формата.
- Все варианты в `srcset` — одного соотношения сторон.
- Не отдавай файл шире ~2× слота.

## LCP-изображение (обычно герой)

- Должно быть `<img>` прямо в HTML, а не CSS-фоном и не `data-src` для JS.
- `fetchpriority="high"` — на 1–2 изображениях максимум. Если картинка только в CSS: `<link rel="preload" as="image" fetchpriority="high">`.
- **Никогда `loading="lazy"` на первом экране.** Lazy — только ниже сгиба.

## Против сдвигов (CLS)

- У каждого `<img>`/`<video>`/`<iframe>` — `width` и `height` (или CSS `aspect-ratio`), в CSS `width:100%; height:auto`.
- Резервируй место под баннеры, рекламу, cookie-плашку, подгружаемые блоки.
- Шрифты: fallback-метрики (`size-adjust`), см. `05-typography.md`.

## Форматы и бюджеты (ориентиры)

| Формат | Качество | Когда |
|---|---|---|
| AVIF | q ≈ 60 | Фото — основной формат; часто на ~50% легче JPEG, но сравнивай |
| WebP | q ≈ 80 | Фолбэк / универсальный |
| JPEG (mozjpeg, progressive) | q ≈ 80 | Последний фолбэк |
| SVG | — | Иконки, логотипы, простые иллюстрации (оптимизируй SVGO) |
| PNG | — | Только когда нужна точная альфа и нет AVIF/WebP |

Бюджеты: герой до ~400 КБ, контентные фото до ~200 КБ. Image CDN (ресайз и формат на лету) + `preconnect` к его домену.

## Плейсхолдеры

| Тип | Размер | Особенность |
|---|---|---|
| Доминантный цвет | 0 | `background-color` контейнера |
| LQIP | 100–200 байт | Картинка ~16px + blur, работает без JS |
| BlurHash | 20–30 символов | Нужен JS для декодирования |
| ThumbHash | ~ то же | Детальнее, хранит пропорции и альфу |

## Видео-фон

```html
<video autoplay muted loop playsinline preload="metadata" poster="hero.jpg"></video>
```

- Без `muted` автозапуск блокируется. `poster` — первый кадр и фолбэк.
- Длина < 10 с, файл < 5 МБ, 720p, без звуковой дорожки, MP4 (H.264) + WebM/AV1.
- WCAG 2.2.2: автодвижение > 5 с — кнопка паузы. Ставь на паузу при скрытой вкладке (`visibilitychange`).
- `prefers-reduced-motion: reduce` → показывай постер вместо видео.
- Текст поверх видео — только со скримом (кадры меняются, контраст тоже).

## Мета-изображения

- **Open Graph / соцсети:** 1200×630 (1.91:1), минимум 600×315, < 1 МБ (жёсткий лимит 5 МБ), JPEG/PNG. Тот же файл подходит для `twitter:card = summary_large_image`. Ключевой текст — в центре с полями (платформы обрезают края).
- **Фавиконы (минимальный набор):** `favicon.ico` 32×32 в корне; `icon.svg` (с тёмной темой через `prefers-color-scheme` внутри SVG); `apple-touch-icon.png` 180×180; в манифесте `icon-192.png`, `icon-512.png` и maskable 512 (безопасная зона — круг диаметром ~409px).

## Alt-текст

| Изображение | Alt |
|---|---|
| Информативное | Коротко смысл в контексте, без «изображение …» |
| Декоративное или дублирует соседний текст | `alt=""` (атрибут не пропускать) |
| Функциональное (в ссылке/кнопке) | Действие или цель: «Поиск», «На главную» |
| Текст в картинке | Тот же текст, если его больше нигде нет |
| Сложное (график, схема) | Короткий alt + полное описание или таблица на странице |

## Лицензии

- Unsplash: коммерческое использование без атрибуции разрешено, но нельзя собирать конкурирующий сервис; про model/property release лицензия не говорит — с узнаваемыми людьми и брендами в рекламе осторожно.
- Храни источник и лицензию каждого ассета. Для AI-изображений проверяй условия генератора.

## Частые ошибки

- Герой задан CSS-фоном; lazy на первом экране.
- Картинка 4000px в слоте 400px.
- Нет размеров — прыгает вёрстка.
- Тяжёлый 1080p-видеофон на мобильном.
- Пустой или бессмысленный alt («image123.jpg»).
