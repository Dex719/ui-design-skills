# 26. Современный CSS и режимы доступности

Источники: MDN, web.dev (Baseline), W3C CSS Working Group (Color 5, Anchor Positioning, View Transitions, Cascade 6), WCAG 2.2, Microsoft (forced colors / High Contrast), WebKit и Chrome release notes. Токены и тёмная тема — `references/04`, `16`; сетки и container queries — `06`; анимация — `08`, `21`.

**Главная мысль.** Многое, что раньше требовало JS, теперь делает CSS: подсветка родителя, позиционирование подсказок, анимация появления, переходы между страницами, тема. Меньше JS — меньше багов и лучше доступность. Но поддержка разная: всё, что не «Baseline widely available», подключай с фолбэком через `@supports`.

## Как решать, можно ли использовать

- **Baseline** (web.dev, MDN, caniuse) — «newly available»: есть во всех основных браузерах; «widely available»: уже 30 месяцев. Для массового продукта ориентир — widely available или фолбэк.
- Новое свойство — как улучшение: без него интерфейс работает и выглядит прилично.
- `@supports (anchor-name: --a) { … }`, `@supports selector(:has(a)) { … }` — проверка внутри CSS; в JS — `CSS.supports(…)`.
- Поддержка ниже меняется быстро — перед использованием проверь актуальные данные, особенно для пунктов с пометкой «проверь».

## Селекторы и каскад

| Что | Зачем в UI | Поддержка |
|---|---|---|
| `:has()` | Стиль родителя по содержимому: карточка с отмеченным чекбоксом, поле-группа с ошибкой (`.field:has(:user-invalid)`), форма с пустым обязательным полем | Baseline 2023 |
| `:user-invalid` / `:user-valid` | Ошибка только после взаимодействия, а не сразу при загрузке (в отличие от `:invalid`) | Baseline 2023 |
| `:focus-visible` | Кольцо фокуса только при клавиатуре | Baseline 2022 |
| Вложенность CSS (`&`) | Компонентные стили без препроцессора | Baseline 2023 |
| `@layer` | Порядок «сброс → токены → компоненты → утилиты» без войны специфичности | Baseline 2022 |
| `@scope` | Стили, ограниченные поддеревом компонента | Chromium и Safari; Firefox — проверь |

## Цвет и тема

- **`oklch()`** — цвета палитры с равномерной светлотой (Baseline 2023). Значения считает `make_palette.py`.
- **`color-mix(in oklch, var(--accent) 12%, transparent)`** — тинты, hover и подложки из токенов без новых переменных (Baseline 2023). Так строятся мягкие фоны статусов и наведение.
- **`light-dark(светлое, тёмное)`** + `color-scheme: light dark` — пара значений в одном токене; переключение темы через `color-scheme` на `:root` (Baseline 2024). Не заменяет отдельный набор токенов, если темы различаются не только цветами.
- **`color-scheme`** — обязательно: без него системные полосы прокрутки, поля дат и `<select>` остаются светлыми в тёмной теме.
- **`accent-color: var(--accent)`** — нативные чекбоксы, радио и ползунки в цвете бренда без перерисовки (Baseline 2022). Проверь контраст ≥ 3:1.

## Раскладка

- **Container queries** (`container-type: inline-size; @container (width > 30rem)`) — компонент подстраивается под место, а не под окно (Baseline 2023). Единицы `cqi` — для шрифта и отступов внутри компонента. Подробно — `references/06`.
- **`subgrid`** — строки карточек выравниваются между соседями: заголовки, тексты и кнопки на одной линии (Baseline 2023).
- **`aspect-ratio`** — место под медиа без скачков (CLS).
- **`text-wrap: balance`** для заголовков (Baseline 2024), **`text-wrap: pretty`** для абзацев (без висячих коротких строк; Chromium и Safari, в остальных просто игнорируется).
- **`field-sizing: content`** — поле ввода растёт под текст, как в чате (Chromium; в остальных — фолбэк на JS-авторазмер).
- **Логические свойства** (`margin-inline`, `inset-block`) — RTL без отдельных стилей.
- **`scrollbar-gutter: stable`** — страница не сдвигается, когда появляется полоса прокрутки (например, при открытии модалки); проверь поддержку в Safari.
- **Динамические единицы** `dvh` / `svh` / `lvh` — высота экрана на мобильном без прыжков из-за адресной строки (Baseline 2022).

## Всплывающие элементы без JS

- **`<dialog>` + `showModal()`** — модалка с фокусом внутри, Esc, `::backdrop` и автоматическим `inert` для остальной страницы (Baseline 2022). Атрибут `closedby="any"` закрывает по клику на фон (Chromium; проверь остальные).
- **Атрибут `popover`** + `popovertarget` — меню, подсказки, выпадающие списки: верхний слой без `z-index`, закрытие по Esc и клику вне (Baseline 2024). `popover="manual"` — без автозакрытия (тосты).
- **Anchor positioning** (`anchor-name`, `position-anchor`, `position-area`, `position-try-fallbacks`) — подсказка или меню привязаны к кнопке и сами переворачиваются у края экрана. Chromium с 2024, Safari 26; в остальных — проверь и держи JS-фолбэк (Floating UI).
- **Анимация появления:** `@starting-style` + `transition-behavior: allow-discrete` анимирует `display` и `overlay` у `dialog` и `popover` (Baseline 2024). Параметры — `references/21`.

## Анимация и переходы

- **View Transitions в одной странице** — `document.startViewTransition(() => обновить DOM)`; общие элементы — `view-transition-name` (Chrome, Safari 18, Firefox 144). Без поддержки — просто мгновенная смена.
- **Между страницами (MPA)** — `@view-transition { navigation: auto; }` в CSS обеих страниц (Chromium, Safari 18.2+; Firefox — проверь).
- **`interpolate-size: allow-keywords`** на `:root` — анимация `height: auto` (аккордеоны) без JS (Chromium). Фолбэк: `grid-template-rows: 0fr → 1fr`.
- **Анимации по скроллу** (`animation-timeline: scroll() / view()`) — индикатор чтения, появление секций (Chromium, Safari 26; Firefox — проверь). Всегда внутри `@media (prefers-reduced-motion: no-preference)`.

## Режимы доступности

### Принудительные цвета (`forced-colors: active`)

Windows «Контрастные темы»: браузер заменяет цвета страницы системными. Пропадают фоны-картинки, `box-shadow`, полупрозрачные подложки и цвета текста.

- **Фокус — через `outline`, не через `box-shadow`:** `outline: 2px solid transparent` в обычной теме превращается в видимую рамку в контрастной.
- Границы, которые в обычной теме прозрачные (`border: 1px solid transparent`), становятся видимыми — так кнопки и карточки не теряют форму.
- Иконки SVG — `fill`/`stroke: currentColor`, тогда они перекрашиваются вместе с текстом.
- Состояния, переданные только фоном (выбранная строка, активная вкладка), — дублируй рамкой, подчёркиванием или иконкой.
- Подстройка: `@media (forced-colors: active) { … }` с системными цветами `Canvas`, `CanvasText`, `LinkText`, `ButtonText`, `ButtonFace`, `Highlight`, `HighlightText`, `GrayText`.
- `forced-color-adjust: none` — только там, где цвет и есть содержание (образцы цвета, графики с легендой).

### Повышенный контраст (`prefers-contrast: more`)

- Рамки полей и карточек — темнее (`--border-strong` вместо `--border`), вторичный текст — ближе к основному, без полупрозрачных подложек под текстом (Baseline 2022).
- `prefers-contrast: less` — редкий запрос, но не стоит его ломать.

### Меньше движения и прозрачности

- `prefers-reduced-motion: reduce` — правила в `references/08` и `21`; библиотека `fx` уже учитывает.
- `prefers-reduced-transparency: reduce` — стекло и размытие заменить плотным фоном (поддержка частичная; без неё стекло всё равно должно давать контраст).

### `inert`

- Атрибут `inert` делает поддерево недоступным для фокуса, клика и скринридера (Baseline 2023). Нужен для самодельных модалок и шторок, офскрин-меню, неактивных шагов мастера. У `dialog.showModal()` уже встроено.

### Масштаб и шрифт

- Размеры шрифта — в `rem`, чтобы работал системный размер шрифта; отступы вокруг текста — тоже в `rem` или `em`.
- Проверь зум 200% и 400% (reflow на ширине 320 CSS px, WCAG 1.4.10) и `text-spacing` (WCAG 1.4.12).

## Чек-лист

- [ ] Новые свойства — с фолбэком; без них интерфейс работает.
- [ ] `color-scheme` задан; нативные контролы в тёмной теме тёмные; `accent-color` с контрастом ≥ 3:1.
- [ ] Модалки — `dialog.showModal()` или `inert` для фона; меню и подсказки — `popover`.
- [ ] Фокус — `outline`, видим в контрастной теме Windows; состояния не держатся только на фоне.
- [ ] `prefers-contrast: more` усиливает рамки и вторичный текст.
- [ ] Анимации по скроллу и View Transitions — внутри `prefers-reduced-motion: no-preference`.

## Анти-паттерны

- Фокус через `box-shadow` — исчезает в контрастной теме.
- `forced-color-adjust: none` на всю страницу.
- Самодельная модалка без `inert`: Tab уходит под затемнение.
- Новое свойство без `@supports` там, где без него ломается раскладка (а не просто пропадает украшение).
- `z-index: 9999` для меню вместо `popover`.
