# 06. Сетки, раскладка, адаптив

Источники: Android window size classes (M3), Bootstrap 5.3, Tailwind, MDN (container queries).

## Колоночная сетка

| Устройство | Колонки | Гаттер | Поле по краю |
|---|---|---|---|
| Мобильный | 4 | 16px | 16px (20–24 для «воздушных» сайтов) |
| Планшет | 8 | 16–24px | 24–32px |
| Десктоп | 12 | 24–32px | авто (контейнер по центру) |

Цифры гаттеров и полей — практические ориентиры, а не стандарт.

- **Ширина контейнера:** обычно 1120–1280px; для широких дашбордов 1440px. Текстовую колонку ограничивай `max-width: 65–75ch` даже внутри широкого контейнера.
- **Full-bleed:** фото и фоновые секции могут выходить за контейнер; контент внутри них — на сетке.
- **Не всё обязано лежать на сетке.** Сетка — для выравнивания, а не клетка. 1–2 намеренных выхода (перекрытие, смещение) оживляют страницу.

## Брейкпоинты

| Система | Брейкпоинты |
|---|---|
| Material 3 / Android (window size classes, ширина) | Compact < 600dp · Medium 600–839 · Expanded 840–1199 · Large 1200–1599 · Extra-large ≥ 1600 |
| Material 3 (высота) | < 480 · 480–899 · ≥ 900 |
| Bootstrap 5 | 576 · 768 · 992 · 1200 · 1400px |
| Tailwind | sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536px |

- Ставь брейкпоинты там, где **ломается контент**, а не под модели устройств.
- Минимум три состояния: компакт, средний, широкий. Один переход «мобайл/десктоп» почти всегда даёт неудобный планшет.
- Mobile-first: базовые стили для узкого экрана, `min-width`-медиазапросы добавляют сложность.

## Container queries

Компонент подстраивается под ширину своего контейнера, а не окна. Лучший выбор для переиспользуемых карточек, виджетов, сайдбаров.

```css
.card-wrap{ container-type: inline-size; }
@container (width > 480px){
  .card{ display:grid; grid-template-columns: 160px 1fr; gap: 16px; }
}
```

Единицы `cqi`/`cqw` — доля ширины контейнера (например, для заголовка карточки).

## Адаптация навигации

| Ширина | Навигация (M3 / общая практика) |
|---|---|
| Compact | Нижний таб-бар (3–5 пунктов) или верхняя панель + меню |
| Medium | Navigation rail (вертикальная узкая панель) |
| Expanded+ | Постоянный сайдбар или верхняя навигация с видимыми пунктами |

Список–детали (list-detail): на compact — два экрана, на expanded — две панели рядом.

## Логические свойства

Используй `margin-inline-start`, `padding-inline`, `inset-inline-end` вместо left/right — раскладка сама зеркалится для RTL (арабский, иврит).

## Мобильные особенности

- Безопасные зоны (вырезы, home indicator): `padding: env(safe-area-inset-bottom)` и `viewport-fit=cover`.
- Высота экрана: `100dvh` вместо `100vh` (адресная строка мобильных браузеров).
- Липкие элементы (хедер + нижняя кнопка + баннер cookies) не должны съедать больше ~25–30% высоты экрана; проверь в ландшафте.
- Горизонтальный скролл страницы недопустим (WCAG 1.4.10 Reflow: контент на 320 CSS px без прокрутки по двум осям).

## Частые ошибки

- Брейкпоинты под iPhone/iPad вместо контента.
- Текст на всю ширину 1920px.
- Одинаковые отступы везде — нет ритма и группировки.
- Сетка карточек с разной высотой картинок и разными соотношениями сторон.
- Фиксированная высота блоков с текстом (ломается при переводе и зуме).
