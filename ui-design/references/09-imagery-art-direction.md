# 09. Изображения, арт-дирекшн, слияние фото с UI, иконки

Источники: NN/g (photos as content, text over images), Ahmad Shadeed, MDN, SGDS iconography, Correll.

## Арт-дирекшн

- **Сначала мудборд, потом фото.** 10–20 референсов → 3–5 правил: «тёплый дневной свет, естественные тени, ненасыщенные цвета, люди в процессе работы, без постановки».
- **Единый визуальный язык.** У всех фото совпадают направление и температура света, цветокоррекция (один пресет/LUT), ракурс, глубина резкости, плотность кадра. Один снимок «из другой серии» заметнее десяти одинаковых.
- **Информативные фото, а не декоративные.** По айтрекингу NN/g люди смотрят на фото, несущие информацию (реальная команда, сам продукт), и пропускают стоковые «фоновые» картинки.
- **Направление взгляда.** Человек на фото смотрит на заголовок или кнопку, а не за край экрана. Эмоциональное лицо, по тестам Correll, побуждает к действию сильнее, чем просто взгляд.
- **Один тип визуала на страницу:** фото, или 3D, или иллюстрации одного стиля. Смесь выглядит как сборная солянка.
- **AI-изображения:** проверяй руки, текст на вывесках, логотипы, пропорции, «пластиковую» кожу, одинаковые лица, плоский свет. Держи стиль через референсы и seed, ретушируй.

**Частые ошибки:** рукопожатия и офисные переговорки; огромное декоративное фото, которое отталкивает контент вниз; стоковые аватарки в отзывах.

## Текст поверх изображений

**Контраст:** 4.5:1 (обычный текст), 3:1 (крупный). Проверяй по **худшему участку** под текстом и для **всех** фото, которые туда могут попасть (карусель, CMS).

**Техники, от мягкой к жёсткой:**
1. Текст в негативном пространстве кадра (небо, стена, размытый фон).
2. Градиентный скрим только под текстом: снизу вверх или слева направо.
3. `text-shadow` как страховка: `0 1px 3px rgb(0 0 0 / .35)`.
4. Размытие или «стеклянная» подложка.
5. Сплошная полупрозрачная плашка.

Ориентир: затемнение 40–60% в зоне белого текста. В тесте NN/g подложка 30% не дала 3:1 на светлых облаках, 50% — дала.

```css
.hero{ position:relative; isolation:isolate; }
.hero img{ position:absolute; inset:0; width:100%; height:100%; object-fit:cover; z-index:-1; }
.hero__scrim{
  /* скрим выше текста за счёт большого верхнего паддинга */
  padding: 6rem 1.5rem 1.5rem; color:#fff;
  background: linear-gradient(to top,
    rgb(0 0 0 / .80) 0%, rgb(0 0 0 / .55) 35%,
    rgb(0 0 0 / .25) 65%, rgb(0 0 0 / 0) 100%);
}
.glass{ background: rgb(255 255 255 / .12); backdrop-filter: blur(16px) saturate(140%); }
```

**Как проверить:** под оверлей поставь сплошной фон самого светлого цвета фото и измерь контраст пипеткой; Firefox DevTools умеет считать контраст на градиентах.

**Фолбэк:** задай фоновый цвет контейнера (тёмный под белый текст) — если фото не загрузилось, текст не окажется белым на белом.

## Слияние фото с интерфейсом

- **Цветовой оверлей в бренде:**
  ```css
  .tint{ background: linear-gradient(oklch(0.35 0.12 255 / .55), oklch(0.35 0.12 255 / .55)), url(p.jpg) center/cover; }
  ```
- **Дуотон** — лучший способ унифицировать разнородные фото: `filter: grayscale(1) contrast(1.1)` + слой цвета с `mix-blend-mode: multiply` (тени) или `screen` (света); либо SVG `feColorMatrix`.
- **Режимы наложения.** `mix-blend-mode` смешивает элемент со всем, что позади; оборачивай группу в `isolation: isolate`, чтобы не задеть фон страницы. `background-blend-mode` — смешивание слоёв фона внутри одного элемента. После блендинга перепроверяй контраст текста.
- **Растворение фото в фоне:** `mask-image: linear-gradient(to bottom, #000 60%, transparent)` или градиент до цвета фона секции — исчезает шов.
- **Формы:** `clip-path` (скос края секции `polygon(0 0,100% 0,100% 85%,0 100%)`, эллипс), SVG-маски.
- **Вырезки (cutout).** Объект без фона выходит за границы карточки или секции (абсолютное позиционирование, отрицательный margin) и создаёт глубину. Нужны чистая маска без ореола и мягкая контактная тень. Формат с альфой: AVIF/WebP/PNG.
- **Единая система с UI:** у фото тот же радиус, что у карточек (токен `--radius`), тот же набор теней. Скруглённые фото рядом с острыми карточками выглядят чужими.
- **Зерно/шум** 3–8% поверх градиентов убирает «пластик» и бандинг (SVG `feTurbulence` или тайл).
- **Слои глубины:** 3–4 плана (фон → фото → карточка → текст/CTA). Элемент, перекрывающий две секции, связывает их — но 1–2 таких перекрытия на страницу, не больше.

**Частые ошибки:** фото вставлено прямоугольником без связи с палитрой; разные радиусы и тени у фото; блендинг убил контраст; ореол вокруг вырезки.

## Кадрирование и фокус

- **2–3 соотношения на проект.** 16:9 — герой и видео; 3:2 / 4:3 — контент и карточки; 1:1 — аватары, сетки; 4:5 — портреты, мобильные посты; 9:16 — сторис, мобильный герой.
- **CSS:** `aspect-ratio: 3/2; object-fit: cover; object-position: 50% 30%`. Для портретов смещай точку вверх, чтобы не резать головы.
- **Safe zone:** лица и ключевой объект — в центральной части кадра (~60%), чтобы пережить кроп 16:9 → 4:5. Правило третей: объект на одной трети, текст на противоположной.
- **Арт-дирекшн через `<picture>`:** на мобильном — отдельный вертикальный кроп, а не уменьшенный горизонтальный.

```html
<picture>
  <source media="(width < 800px)" srcset="hero-portrait.avif" width="800" height="1000">
  <img src="hero-wide.jpg" width="1600" height="900" alt="Клиент оплачивает покупку телефоном">
</picture>
```

**Частые ошибки:** обрезанные лица и макушки; разные соотношения в одной сетке карточек; горизонтальный кадр, ужатый на мобильном до нечитаемости.

## Иконки

### Эмодзи запрещены

**Никогда не используй эмодзи** в интерфейсе: в кнопках, заголовках, пустых состояниях, списках, бейджах, игровых слотах и тостах.

Почему:
- эмодзи на каждой платформе нарисованы по-разному (Apple, Google, Microsoft, Samsung);
- их нельзя перекрасить в цвет темы и токенов;
- толщина линий и стиль не совпадают с набором иконок;
- скринридер зачитывает их длинными названиями;
- они сразу выдают шаблонный, сгенерированный интерфейс.

То же касается текстовых символов, которые браузер может показать как эмодзи: ★ ☆ ✓ ✔ ✕ ✖ ⚠ ⚡ ❤ ☀ ☰ ⋯ → ⬆. Стрелки и «⋯» в интерфейсе тоже рисуются иконками. Исключение — пользовательский контент: эмодзи в сообщениях и реакциях пользователей показываются как есть.

### Откуда брать иконки

1. **Готовый набор скилла:** `assets/icons/` — Lucide (ISC), 118 иконок по группам. `python3 scripts/icon.py <имя>` выдаёт inline-SVG с `stroke="currentColor"`; `--list` — все имена, `--sprite` — спрайт `<symbol>`.
2. **Нет нужной иконки — скачай из открытого набора того же стиля:**
   - Lucide (lucide.dev, ISC, 1 600+);
   - Tabler Icons (MIT, 5 900+, тот же стиль 24/2 px);
   - Phosphor (MIT, 6 весов);
   - Material Symbols (Apache 2.0, вариативный вес и заливка);
   - для игр — game-icons.net (CC BY 3.0, нужна атрибуция) и Kenney (CC0).
   Через npm: `npm i lucide-static`, файлы лежат в `node_modules/lucide-static/icons/<имя>.svg`.
3. **Нет и там — нарисуй SVG сам** по правилам набора: viewBox `0 0 24 24`, живая область 20×20, обводка 2 (или та же, что у набора), `stroke-linecap="round" stroke-linejoin="round"`, без заливки, только простые фигуры (`path`, `circle`, `rect`, `line`). Проверь рядом с соседними иконками в 16 и 24 px.
4. **Логотипы брендов** (платёжные системы, соцсети) бери только из официальных брендбуков.

**Не смешивай наборы.** Если взял иконку из другого набора, подгони толщину и скругления или нарисуй её заново.

### Правила набора

- **Сетка 24×24**, живая область ~20×20, отступ 2px. Размеры: 16 / 20 / 24 / 32 / 48.
- **Одна толщина обводки** на весь набор (1.5px или 2px при 24px), одинаковые скругления и окончания линий.
- **Один стиль:** outline или filled. Filled допустим для активного состояния того же значка.
- **Оптическое выравнивание:** треугольник «play» сдвигают вправо, круги делают чуть крупнее квадратов; иконку выравнивают по центру строки текста, а не по рамке.
- **Подписи:** без подписи только общепринятые (поиск, закрыть, меню, назад). Остальное — иконка + текст.
- **Один набор** на продукт (Lucide, Phosphor, Material Symbols — что-то одно).

**Частые ошибки:** эмодзи вместо иконок; символ ★ или ✓ текстом; иконки из 3 наборов; разная толщина; иконка-загадка без подписи; иконка не того размера, растянутая на 1px.

## Иллюстрации

- Фото — для доверия, людей и реального продукта; иллюстрации — для абстрактных понятий, пустых состояний, онбординга, ошибок.
- Один иллюстратор или одна библиотека; палитра иллюстраций — из токенов бренда.
- 3D, glassmorphism, градиентные «блобы»: проверяй контраст текста на стекле, нагрузку `backdrop-filter` на слабых устройствах; генерический 3D-блоб быстро устаревает и выглядит шаблонно.
