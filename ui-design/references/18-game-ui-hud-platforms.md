# 18. Игры: типы UI, HUD, безопасные зоны, геймпад, платформы

Источники: Fagerholt & Lorentzon (2009), Xbox Accessibility Guidelines (XAG 101, 102, 107, 112, 113), Xbox GDK screen areas, Steam Deck compatibility, Kotaku (кнопки в Японии).

## Четыре типа игрового UI

Классификация по двум вопросам: существует ли элемент в мире игры (видит ли его персонаж) и находится ли он в 3D-пространстве.

| Тип | В мире игры? | В 3D? | Пример | Сильная сторона | Риск |
|---|---|---|---|---|---|
| **Диегетический** | да | да | Полоска здоровья на костюме (Dead Space), часы на руке | Погружение | Медленно читается |
| **Недиегетический** | нет | нет | Классический HUD поверх кадра | Скорость, ясность | Разрушает погружение при перегрузе |
| **Пространственный** | нет | да | Обводка союзников, маркер цели над объектом | Связь с местом | Шум в сцене |
| **Мета** | да | нет | Кровь на «камере», виньетка при уроне | Эмоция | Мешает видеть |

- Решение о диегетике принимается на старте, а не латается HUD-ом потом. Полностью диегетический интерфейс в Far Cry 2 оказался почти непрактичным; Dead Space пришлось добавлять отдельный «локатор».
- Соревновательные игры почти всегда нуждаются в недиегетических элементах: скорость чтения важнее погружения.
- Смешанный подход работает, если у каждого типа своя логика (Team Fortress 2).

## HUD

**Приоритеты информации:**
1. Выживание и решение «прямо сейчас»: здоровье, боезапас, угрозы, прицел.
2. Цели, мини-карта, способности на перезарядке.
3. Прогресс, валюта, мета-информация.
4. Всё остальное — в меню паузы.

**Правила:**
- **Контекстный (динамический) HUD:** элемент появляется при изменении (урон, перезарядка, подбор), держится несколько секунд и гаснет. Критичные значения (мало HP, патронов) не прячутся.
- **Размещение:** постоянные элементы — по углам и краям, в периферийном зрении; центр — для прицела и действия. Мини-карта обычно в углу, здоровье и патроны — внизу (конвенция жанра, не стандарт).
- **Читаемость на 3D-фоне:** контраст считают против самого светлого и самого тёмного участка фона (XAG 102): текст 4.5:1, крупный текст и иконки 3:1, высококонтрастный режим 7:1. Приёмы — обводка, тень, подложка с регулируемой непрозрачностью, выбор цвета HUD.
- **Цифры урона:** размер/цвет по силе удара, критический урон выделен формой, а не только цветом; отключаемы.
- **Прицел:** настраиваются форма, цвет, размер; хитмаркер подкреплён звуком.
- **Опции:** скрыть HUD целиком и по элементам, масштаб, прозрачность.

**Частые ошибки:** белый текст без обводки на светлом небе; HUD в центре экрана; информация только цветом; нет опций скрытия и масштаба.

## Безопасные зоны и масштаб

- **TV safe zones (Xbox GDK):** action-safe — внутренние 95% кадра, title-safe — внутренние 90%. При 1080p title-safe = 1720×1000 px (поля 96 px слева/справа, 40 px сверху/снизу). Меню и критичный HUD — внутри title-safe.
- Внутри action-safe полосы 32 px по бокам и 8 px сверху/снизу могут занимать системные элементы Xbox.
- **Ultrawide:** HUD привязывай к краям зоны 16:9 или дай слайдер ширины HUD; растянутый на 32:9 HUD уводит информацию из периферии в «никуда».
- **Мобильные:** учитывай вырезы и home indicator через системный safe area.

## Минимальный размер текста (XAG 101)

Высота от нижнего до верхнего выносного элемента, при настройках по умолчанию:

| Платформа | Минимум |
|---|---|
| Консоль, 1080p | 26 px |
| Консоль, 4K | 52 px |
| ПК / VR, 1080p | 18 px |
| ПК / VR, 4K | 36 px |
| Мобильные, 100 / 200 / 400 DPI | 18 / 36 / 72 px |
| Steam Deck (1280×800) | минимум 9 px, рекомендуется 12 px; читаемо с 30 см |

- Масштаб текста и иконок до **200%** без потери смысла и без прокрутки по двум осям.
- Интервалы (XAG 101): межстрочный 1.5×, межабзацный 2× межстрочного, трекинг 0.12em, межсловный 0.16em, строка ≤ 80 знаков (≤ 40 для CJK); опция без капса; выравнивание по языку, а не по центру.
- **10-foot UI** (ТВ с дивана): крупные элементы, мало элементов на экран, явный фокус, никаких hover-подсказок.

**Частые ошибки:** ПК-размеры текста на консоли; HUD вплотную к краю на ТВ; нет слайдера масштаба UI.

## Навигация с геймпада

- **Весь UI проходится геймпадом** — D-pad/стик и кнопки, без мыши и без эмуляции курсора (XAG 112). Каждое действие — одним нажатием, без комбинаций.
- **Фокус (XAG 113):** всегда виден на любом фоне, включая анимированный; комбинируй сигналы (рамка + увеличение + заливка); никогда не уходит на скрытые элементы; диалог забирает фокус на первый контрол и не выпускает наружу.
- **Порядок:** логичный, иначе — визуальный. Линейные меню зацикливаются, сетки — нет (желательна опция отключить зацикливание).
- **Устойчивые раскладки:** LB/RB — вкладки, LT/RT — страницы, «Назад» на каждом подэкране с постоянной подсказкой кнопки.
- **Запоминание позиции:** при возврате в меню фокус там, где был.
- **Глифы кнопок** соответствуют активному устройству и меняются мгновенно при смене ввода. Steam Deck прямо запрещает клавиатурные глифы при активном геймпаде. Терминология и иконки — платформенные.
- **Подтверждение / отмена — по позиции кнопки на платформе, а не по букве:**
  - Xbox: A (нижняя) — подтвердить, B (правая) — отменить.
  - Nintendo: A (правая) — подтвердить, B (нижняя) — отменить.
  - PlayStation: × (нижняя) — подтвердить, ○ — отменить; в Японии до PS4 включительно было наоборот, на PS5 Sony перевела Японию на × для подтверждения.
- **Разрушительные действия** (удалить сохранение, продать предмет): удержание с индикатором прогресса или диалог с фокусом по умолчанию на безопасном варианте. Удержание 2–3+ с — барьер доступности (XAG), нужна альтернатива-переключатель.
- **Текстовый ввод:** вызывай системную экранную клавиатуру.

**Частые ошибки:** невидимый фокус; курсор-эмуляция мыши; неверные глифы; лаунчер, который проходится только мышью.

## Мобильные игры

- Зоны касания (XAG 107): телефон ≥ 15×15 мм (≈ 59 px при 100 DPI), планшет ≥ 24×24 мм.
- Кнопки срабатывают по отпусканию, а не по нажатию (можно передумать, сдвинув палец).
- Виртуальные контролы игрок может двигать и масштабировать.
- Важное — в зонах больших пальцев (нижние углы в ландшафте); верх экрана — для информации, не для частых действий.

## Платформенные требования (верхний уровень)

- **Steam Deck Verified:** текст ≥ 9 px при 1280×800; глифы по активному устройству; полный доступ с геймпада по умолчанию, включая лаунчер; экранная клавиатура для ввода; без предупреждений о «неподдерживаемом устройстве».
- **Xbox / PlayStation / Nintendo:** правильная платформенная терминология и глифы, safe area, обработка смены пользователя и отключения контроллера. Детали — в закрытых требованиях сертификации (TCR / TRC / Lotcheck), сверяйся с документацией платформы.
