# 14. Визуализация данных и дашборды

Источники: NN/g (choosing chart types), Datawrapper Academy, Okabe & Ito (палитра), Apple HIG (charts).

## Выбор графика

| Задача | График |
|---|---|
| Сравнить величины | Столбцы (вертикальные); с длинными подписями — горизонтальные |
| Тренд во времени | Линия |
| Связь двух переменных | Точечный (scatter) |
| Доля целого (2–3 части) | Столбец 100% или одна полоса; круговую — только при 2–3 секторах |
| Распределение | Гистограмма, box plot |
| Одно ключевое число | KPI-карточка со сравнением |
| Точные значения | Таблица |

Избегай: 3D-графиков, круговых с 6+ секторами, двух осей Y без крайней необходимости, «радаров» для непрофессиональной аудитории.

## Правила честности

- **Столбцы начинаются с нуля** — иначе разница преувеличена. Линии и scatter могут начинаться не с нуля, если это подписано.
- Одинаковые масштабы при сравнении нескольких графиков рядом.
- Не обрезай период так, чтобы спрятать неудобный участок.

## Цвет в графиках

- **Okabe–Ito** (безопасна для дальтоников): `#E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7 #000000`.
- Категориальная палитра — до 6–8 цветов; больше — группируй в «Прочее».
- Последовательные данные — одна шкала светлоты одного оттенка; расходящиеся (минус/плюс) — два оттенка от нейтрального центра.
- Цвет дублируй формой маркера, штриховкой или подписью. Пара красный/зелёный — никогда как единственный код.
- Выделение: главная серия — акцентом, остальные — серыми.

## Подписи и чтение

- Подписывай серии прямо у линий вместо легенды, если серий ≤ 5.
- Заголовок графика = вывод: «Расходы на доставку выросли на 18% за квартал», а не «Расходы, Q3».
- Единицы измерения в заголовке или у оси; округление до значимых разрядов; табличные цифры.
- Тултипы при наведении дублируй доступными значениями (таблица под графиком или `aria-label`).

## Дашборды

- **Иерархия:** сверху 3–5 главных KPI, ниже — тренды, ещё ниже — детали и таблицы. Важное — сверху слева.
- **KPI-карточка:** значение + сравнение (с прошлым периодом, с целью) + направление (стрелка + цвет + текст «+12%»). Число без контекста ничего не говорит.
- Один экран — один вопрос или одна роль пользователя.
- Фильтры периода и сегмента — сверху, их состояние всегда видно.
- Состояния: загрузка (скелетон графика), нет данных, частичные данные, ошибка источника.
- Плотность: для аналитиков можно плотнее (14px, компактные таблицы), для руководителей — крупные числа и выводы.

## Таблицы

- Числа — по правому краю, текст — по левому, табличные цифры.
- Заголовки столбцов закреплены при скролле; первая колонка закреплена при горизонтальном скролле.
- Зебра или разделители — что-то одно, тонко.
- Сортировка с видимым индикатором; массовые действия при выборе строк.
- На мобильных — карточки вместо широкой таблицы или горизонтальный скролл с закреплённой первой колонкой.

## Частые ошибки

- 3D и круговые с 8+ секторами.
- Обрезанная ось у столбцов.
- Красный/зелёный как единственный код.
- KPI без сравнения.
- 12 одинаковых виджетов без иерархии.
