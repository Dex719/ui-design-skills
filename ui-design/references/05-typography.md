# 05. Типографика

Источники: Брингхерст (webtypography.net), WCAG 1.4.8 / 1.4.12, Material 3, Apple HIG, Baymard.

## Основные параметры

| Параметр | Норма | Частая ошибка |
|---|---|---|
| **Базовый размер** | 16px (1rem) для веба; 14–16px в плотных B2B-таблицах. M3: bodyLarge 16/24, bodyMedium 14/20, bodySmall 12/16. HIG: body 17pt, минимум 11pt. | 12px для основного текста. В iOS Safari поле с текстом < 16px вызывает автозум — ставь ≥ 16px, а не `maximum-scale=1`. |
| **Модульная шкала** | 1.2 (Minor Third) или 1.25 (Major Third) для интерфейсов; 1.333 (Perfect Fourth) для контентных сайтов. | Размеры «на глаз»: 13, 15, 17, 19, 23px. |
| **Межстрочный** | 1.5–1.6 для текста; 1.05–1.25 для крупных заголовков (по размеру — `references/23`, раздел 1). Чем шире колонка, тем больше межстрочный. | `line-height: 1.5` у заголовка 48px — строки распадаются. |
| **Длина строки** | 45–75 символов, идеал ≈ 66 (Брингхерст). WCAG AAA: ≤ 80 (≤ 40 для CJK). В CSS: `max-width: 65ch`. | Текст на всю ширину 1440px. |
| **Трекинг** | Текст: 0. Крупные заголовки: −0.01…−0.03em. КАПС: +0.05…+0.1em. | Капс без разрядки, мелкий текст со сжатым трекингом. |
| **Гарнитуры** | 1 семейство (хватает в 90% случаев) или 2 (акцидентная + наборная). | 3–4 шрифта в продукте. |
| **Начертания** | 2–3 веса (400, 500/600, 700). | 6 весов, отличающихся на 100. |

## Шкала по умолчанию (база 16, ×1.25)

| Стиль | Размер / межстрочный | Вес |
|---|---|---|
| Display | 48 / 52 | 700 |
| H1 | 39 / 44 | 700 |
| H2 | 31 / 36 | 600 |
| H3 | 25 / 32 | 600 |
| Body L | 18 / 28 | 400 |
| Body | 16 / 24 | 400 |
| Small / Caption | 14 / 20 | 400–500 |
| Overline / Label | 12 / 16, капс +0.08em | 600 |

Округляй до шага 4px по межстрочному, чтобы держать вертикальный ритм.

## Адаптивный размер

Плавный размер заголовков без кучи брейкпоинтов:

```css
h1{ font-size: clamp(2rem, 1.2rem + 3vw, 3.25rem); line-height: 1.1; }
```

Базовый текст оставляй в `rem`, не в `vw`: иначе ломается пользовательский зум (WCAG 1.4.4 — увеличение до 200%).

## WCAG 1.4.12 — интервалы текста

Вёрстка не должна ломаться, если пользователь задаст: межстрочный 1.5×, межабзацный 2×, трекинг 0.12em, межсловный 0.16em. Не фиксируй высоту текстовых контейнеров.

## Кириллица и мультиязычность

- Проверь, что в шрифте есть кириллица, казахские буквы (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І), знак ₸ и нужные кавычки «».
- Русский и казахский текст длиннее английского; кнопки и табы закладывай с запасом (см. `13-ux-writing-i18n.md`).
- Для CJK — отдельный fallback-шрифт и больший межстрочный.

## Загрузка шрифтов

- WOFF2, сабсет по нужным языкам, `font-display: swap` (или `optional` для не-критичных).
- Предзагрузка только для 1–2 критичных начертаний: `<link rel="preload" as="font" type="font/woff2" crossorigin>`.
- Настрой fallback-метрики (`size-adjust`, `ascent-override`), чтобы при подмене шрифта не прыгала вёрстка (CLS).
- Вариативный шрифт заменяет несколько файлов начертаний, если весов нужно 3 и больше.

## Числа и данные

- В таблицах и суммах — табличные цифры: `font-variant-numeric: tabular-nums`.
- Суммы: выравнивание по правому краю, разделитель разрядов по локали (`12 500,00 ₸`), валюта в одном месте.
- Даты и числа форматируй через `Intl`, не вручную.

## Частые ошибки

- Центрированный текст длиннее 2–3 строк.
- Курсив и капс для длинных фрагментов.
- Заголовки, визуально оторванные от своего текста (одинаковые отступы сверху и снизу).
- «Висячие» предлоги и союзы в конце строки заголовка (в вебе — `text-wrap: balance` для заголовков, `text-wrap: pretty` для абзацев).
