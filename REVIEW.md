# Ревью скиллов ui-design и ui-design-slim (2026-10-16)

Счётчики сходятся: 118 иконок, 17 палитр, 44 функции `fx` / ~49 эффектов в каталоге.

## Критично

1. **`check_contrast.py` выдаёт PASS на плохом контрасте.** Альфа отбрасывается (`scripts/check_contrast.py:75-86`): `rgb(0 0 0 / .1)` на `#fff` → 21:1. В палитрах «тёмная по умолчанию» (coral-midnight, lime-graphite, plum-night) настоящая светлая тема не проверяется. В режиме пары код выхода всегда 0.
2. **6 из 17 палитр не воспроизводятся командами из `references/20`**: lime-graphite, ocean-navy, sakura, plum-night, forest, sky-bright. У `game-amber` заявлена тёмная тема по умолчанию, но без `--dark-first`.
3. **`make_palette.py` теряет хрому при подборе светлоты** (`ensure()`, `:61-69`): `--max-l 0.95` → серый `#697782`.
4. **Числа противоречат друг другу:** хитстоп (2–4/5–8/10–15 кадров против 8/12/16), длительность каскада (500–600 мс против «100–300, > 500 затянуто»), шаг каскада 60 против 40 мс, межстрочный (1.5–1.6 / 1.5–1.65 / 1.4–1.6).
5. **Скрипты падают в консоли Windows cp1251/cp866** (`UnicodeEncodeError` на «≈», «—»). Исправление: `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`.

## Важно

- **Механика:** slim весит 44 КБ — в 2,4 раза больше SKILL.md полной версии; ужать до 15–20 КБ. Триггеры двух скиллов почти одинаковые. Маршруты в MAP тянут ~150 КБ; mermaid-диаграмма зря расходует токены. Пути вида `python3 scripts/...` работают только из папки скилла.
- **CRLF** ломает shebang на Linux/macOS → `.gitattributes` с `* text=auto eol=lf`.
- **Скрипты:** `--help` падает у `check_contrast` и `build_motion_override`. Нет проверки входа у `make_palette`. `style_tiles` падает с KeyError на неполном JSON и не читает JSON с BOM; `--check` всегда возвращает 0. Официальный `system.example.json` получает предупреждение «синий по привычке». `icon.py --label` не экранируется. Нет иконок `undo-2`, `wifi-off`, `globe`, `square`, `circle-help` и др.
- **effects.js:**
  - `success()` вставляет `opts.label` через innerHTML — XSS;
  - `copy()` навсегда залипает на «Скопировано» при двойном клике;
  - `fieldError()` затирает `aria-describedby`;
  - `loading()` через `disabled` теряет фокус;
  - у `tabs()` нет стрелок и roving tabindex, обработчик resize утекает;
  - у `toast()` нет кнопки «Закрыть» и паузы;
  - первое объявление `announce()` теряется;
  - `flash()` не ограничивает частоту;
  - API несогласованное: порядок аргументов, возвращаемые значения, нет ESM, `.d.ts` и i18n.
- **effects.css:** бесконечные `fx-beat`/`fx-glow`/`fx-tick`; блок `data-motion="full"` дублирует половину файла. `demo.html` содержит встроенную копию `effects.js`.
- **Факты:** пример DTCG `"$value": "#2563EB"` устарел — в 2025.10 значение цвета задаётся объектом. Title-safe 90% при 1080p — это 1728×972, а не 1720×1000. Тёмная тема `#121212` и 87/60/38% — это Material 2, не M3.
