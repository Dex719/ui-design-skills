# UI/UX-дизайн: slim

Сжатая версия полного скилла `ui-design`. Правила и числа проверены по первоисточникам (WCAG 2.2, Material 3, Apple HIG, NN/g, Xbox Accessibility Guidelines).

## Процесс

1. Контекст: тип продукта, платформа, главная задача экрана, одно главное действие, аудитория.
2. **Система до экранов** (раздел 0): бриф в 3 словах + одно «не» → оси характера → параметры, каждый с причиной. Сделай одну HTML-страницу с 2–3 вариантами рядом (заголовок, текст, кнопки, карточка с числом, поле, статусы, иконки, образцы цвета, лесенка размеров, список решений с причинами). Варианты различаются минимум по 3 осям. После выбора — только токены выбранного варианта. Если спросить некого, выбери сам и напиши, почему.
3. Порядок: контент → иерархия и группировка → сетка и отступы → типографика → цвет → изображения → анимация.
4. Все состояния: идеальное, пустое, загрузка, ошибка, офлайн, крайние данные, фокус.
5. Чек-лист в конце файла — перед сдачей.

## 0. Система с нуля: шаблонов нет, у каждого значения — причина

**Оси характера → параметры:**

| Ось | Что двигает |
|---|---|
| Энергия: спокойно ↔ громко | Хрома 0.05 → 0.20, шкала ×1.2 → ×1.5, вес заголовка 500 → 800, движение |
| Формальность: строго ↔ дружелюбно | Радиус 0–4 → таблетка; гротеск или антиква → округлый шрифт |
| Плотность: воздух ↔ данные | База 18 → 14, шаг отступов, контрол 52 → 32 |
| Температура: холодно ↔ тепло | Нейтрали slate → sand, тон акцента |
| Вес: легко ↔ плакатно | Веса, рамки 0–1 → 2–3, тени мягкие → жёсткие смещённые |
| Жанр: классика ↔ техно | Антиква → геометрический или моноширинный шрифт |

**Размеры шрифта по ролям** (приложение / лендинг / дашборд): caption 12–13 / 13–14 / 11–12 · secondary 14 / 14–15 / 12–13 · body 16 (iOS 17) / 17–20 / 13–14 · lead 18–20 / 20–24 · H3 18–20 / 22–28 / 15–16 · H2 22–28 / 32–44 / 18–20 · H1 28–34 / 44–64 / 22–24 · display 40–56 / 64–120 / 32–40 · label 12–13 КАПС +0.06em 600. Минимум 12.

**База** — по расстоянию и аудитории: данные 13–14 · приложение 16 · iOS 17 · чтение 18–20 · 55+ 18–20 (и контраст AAA) · киоск 20–24 · ТВ 24–28 при 1080p.

**Шкала** — по числу уровней и ширине экрана: ×1.125–1.2 плотно и мобильный · ×1.25 приложение · ×1.333 медиа · ×1.5–1.618 промо, только десктоп (на мобильном меньше, через `clamp()`). 5–7 уровней; больше — весом и цветом.

**Заголовок к тексту:** H1/body 1.6–2× плотное приложение · 2–2.5× приложение · 2.5–3.5× медиа · 3–4× лендинг; display/body 2.5–8×. Близкие размеры разводи весом (разница ≥ 200).

**Межстрочный и трекинг от размера:** 12–14 → 1.45–1.6 · 16–20 → 1.5–1.6, 0 · 22–32 → 1.25–1.35 · 36–56 → 1.1–1.2, −0.01…−0.02em · 64+ → 0.95–1.05, −0.02…−0.04em · КАПС +0.05…+0.1em.

**Отступы:** база 4 (плотно, мобильный) или 8 (воздух). Плотная шкала 2·4·6·8·12·16·24·32 (контрол 32–36) · обычная 4·8·12·16·24·32·48·64 (40–44) · воздушная 4·8·16·24·32·48·72·96 (48–56). По уровням ×1.5–2: иконка↔текст 0.5em · поле↔подпись 4–8 · поля группы 12–16 · группы 24–32 · блоки 32–48 · секции 64–128.

**Пропорции компонентов:**
- контрол: 24–28 чипы · 32–36 плотно · 40 десктоп · 44 iOS · 48 Android и главная · 52–56 CTA и 55+; в ряду одна высота; размеры sm/md/lg с шагом 8;
- кнопка: горизонтальный отступ 1–1.5em, ширина ≥ 2× высоты;
- радиус от высоты h: строго 0–2 · точно h/10 · нейтрально h/6–h/5 · мягко h/4 · таблетка h/2; вложенный = внешний − отступ; 3–4 значения на систему;
- иконка ≈ межстрочный текста (16 → 20); обводка 1.5 при тексте 400, 2 при 600;
- рамка 1, фокус 2–3 с отступом 2; тень: смещение ≈ ½ размытия, 5–15%; в тёмной теме — светлее поверхность вместо тени;
- раскладка: текст 65ch · основное:боковое 2:1, 3:1 или 62/38 · сайдбар 240–280 · 3–4 карточки в ряд (мин. 260–320) · шапка 56–64;
- изображения: герой 16:9 (моб. 4:5) · превью 3:2/4:3 · товар 3:4/4:5 · аватар 1:1 · OG 1200×630; одна пропорция на тип контента.

**Цветовая гамма за 7 шагов:**
1. Нейтрали — 60–80% экрана: температура (slate, sand, sage, olive, mauve, gray), светлая или тёмная тема по умолчанию, контраст поверхностей 2–3% (тихо) или 5–8% (плотно).
2. Тон акцента из смысла (материалы, природа, эпоха) и в стороне от 3 конкурентов. Перегружены: бирюза 180–210, синий 220–250, индиго-фиолетовый 260–295 — только с причиной.
3. Хрома из энергии: 0.04–0.08 тихо и дорого · 0.09–0.13 уверенно · 0.14–0.18 ярко · 0.19+ только мелкие акценты.
4. Схема светлоты: тёмный акцент с белым текстом (L 0.45–0.60) · глубокий (0.30–0.42) · яркий с тёмным текстом (0.80–0.88) · светлый на тёмной теме.
5. Пропорция 60/30/10, акцент ≤ 10%: главная кнопка, ссылки, выбранное, одна фирменная деталь. Второй цвет — только для данных или бренда, ±30° или +180° в доле 90/10. Акцент не совпадает со статусом «успех».
6. Варианты различаются минимум по 3 из 5: семья тона, хрома, нейтрали, светлая или тёмная по умолчанию, схема светлоты акцента.
7. Контраст в обеих темах + проверка в оттенках серого.

**Записывай систему:** `name`, `brief`, `color{hue, chroma, neutral, accent_l, bright, dark_first, why}`, `type{display, body, mono, base, ratio, display_max, line, heading_line, why}`, `space{scale, control, why}`, `shape{radius[3], button: rect|pill|chamfer, border, why}`, `depth{style: flat|soft|hard|glow|hairline, why}`, `motion{level, why}`, `signature` — одна фирменная деталь на всех экранах.

## 1. Восприятие

- **Не заставляй думать** (Круг): кликабельное выглядит кликабельным; люди сканируют по F/Z и жмут первое разумное.
- **Норман:** у каждого действия есть видимый сигнал (signifier), реакция (feedback), естественное соответствие (mapping) и ограничения от ошибок (constraints). Интерфейс — по модели пользователя, не по базе данных.
- **Отклик:** 0,1 с — мгновенно; 0,4 с — порог вовлечённости (Доэрти); > 1 с — спиннер; > 10 с — прогресс, оценка времени, отмена. Для частых обратимых действий — оптимистичный UI.
- **Фиттс:** важное — крупнее и ближе; на мобильных — в нижней трети. Опасное — подальше от безопасного.
- **Хик:** меньше вариантов за раз, прогрессивное раскрытие, выделенный рекомендуемый вариант.
- **Якоб:** стандартные паттерны для стандартных задач.
- **Память:** группы по 3–5 (Коуэн ~4); числа чанками (`4400 1234 5678 9010`); не заставляй помнить данные с прошлого экрана.
- **Теслер:** сложность — на систему (автозаполнение, умные умолчания, запоминание выбора).
- **Гештальт:** внутренний отступ группы < внешнего; одинаковый вид = одинаковая функция; карточка объединяет сильнее расстояния.
- **Нильсен:** статус системы, язык пользователя, Undo, единообразие, предотвращение ошибок, узнавание вместо вспоминания, горячие клавиши, минимализм, понятные ошибки, контекстная справка.

## 2. Визуальная иерархия

- **CRAP:** контраст (разное — радикально разное), повторение, выравнивание по общим линиям, близость.
- Иерархия **весом и цветом**: первичный текст почти чёрный, вторичный средне-серый, третичный светло-серый (≥ 4.5:1). Ослабляй второстепенное.
- Лейблы вторичны: показывай значение крупно, название поля мелко или никак.
- **Кнопки:** одна Primary (заливка) на экран; Secondary — контур; Tertiary — текст; деструктивная — серая, красная только в подтверждении.
- **Отступы:** 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96. Начинай с избытка. Секции лендинга 64–96px (моб.) / 96–160px (деск.).
- **Рамки — в последнюю очередь:** разделяй фоном, тенью, отступом. Тени 3 уровня. Радиусы 3–4 значения; вложенный = внешний − отступ.
- **Тест прищуривания:** при размытии видны заголовок, главное действие и 2–4 блока.

## 3. Цвет и контраст

- **60–30–10:** нейтральный фон / вторичный / акцент.
- **WCAG AA:** текст 4.5:1; крупный (≥ 24px или ≥ 18.66px bold) 3:1; элементы UI и графика 3:1. AAA 7:1. Норма — WCAG 2.2 (WCAG 3 — черновик, APCA не нормативен).
- **Смысл не только цветом** (~1 из 12 мужчин — нарушения цветовосприятия): цвет + иконка + текст.
- Семантика: синий — инфо, зелёный — успех, янтарный — внимание, красный — ошибка; по 3 тона (фон, рамка, текст).
- Не ставь серый текст на цветной фон, жёлтый текст на белый; вместо `#000` — почти чёрный (`#0F172A`).
- Палитры строй в **OKLCH** (равномерная светлота), шкала 50–900, проверяй контраст всё равно.
- **Тёмная тема:** по системной настройке, не инверсия; поверхности тёмно-серые и слегка тонированные (Radix: bg `#111113`, surface `#18191b`; в M3 — тона 6/10/12/17/22), выше = светлее; акценты светлее и менее насыщены; текст — не чистый белый (`#edeef0`), вторичный и disabled — отдельными токенами с проверкой контраста; проверяй обе темы.

## 3a. Палитры: решения из брифа, значения — расчётом

- **Почему ИИ-цвета плохие:** индиго-фиолетовый по умолчанию (H 260–295, Tailwind `indigo-500`), градиенты индиго → фиолетовый, хрома под край sRGB (C ≈ 0.23+), чистый серый без оттенка, много равноправных цветов, неон на чёрном.
- **Мягко и дорого:** один акцент + нейтрали с тоном акцента (OKLCH C 0.003–0.006 для фонов, 0.01–0.02 для рамок); хрома акцента 0.06–0.10 мягко, 0.11–0.15 уверенно; off-white фон (L 0.97–0.99) и почти чёрный текст (L 0.15–0.25) с оттенком; поверхности отличаются на 2–5% светлоты, текст — 12–16:1; бейджи и статусы — цветной текст на тинте.
- **Пары нейтралей (Radix):** mauve — красные/розовые/фиолетовые; slate — синие; sage — бирюза; olive — травяные; sand — жёлтые/оранжевые/коричневые.
- **Кнопка с белым текстом (WCAG):** синие/красные/фиолетовые — OKLCH L ≤ ~0.55; зелёные/бирюзовые/оранжевые/янтарные — L ≤ ~0.50. Яркие жёлтый, янтарь, лайм, мята — только с тёмным текстом. В тёмной теме кнопка светлая (L ≈ 0.78) с тёмным текстом.
- **Рецепт:** 1) 2–3 слова настроения + предмет страницы; 2) тон акцента из предмета, хрома по настроению; 3) нейтрали по тону; 4) шкала заранее, не `lighten()`; 5) проверка контраста в обеих темах и в оттенках серого.
- **Примеры для калибровки, не шаблоны** (из полного скилла, контраст всех пар проверен). Бери как отправную точку, только если параметры совпали с выведенными по разделу 0. Остальные токены: `surface` = `#ffffff` в светлой; `on-accent` = `#ffffff` в светлой и = `bg` в тёмной; статусы — Radix (светлая: success `#218358` на `#e6f6eb`, warning `#ab6400` на `#fff7c2`, danger `#ce2c31` на `#feebec`; тёмная: `#3dd68c` на `#132d21`, `#ffca16` на `#302008`, `#ff9592` на `#3b1219`).

## 4. Типографика

- База и шкала — по разделу 0 (поле ввода в iOS ≥ 16px, иначе автозум).
- Гарнитура по характеру: нейтрально — Onest, Manrope, Golos Text, Inter; точно — IBM Plex, Unbounded (заголовки); редакционно — Playfair Display, Lora, PT Serif + гротеск; премиально — Prata, Cormorant Garamond + Jost; мягко — Nunito, Rubik; игры — Russo One, Exo 2. Вторая гарнитура — только ради контраста.
- Межстрочный 1.5–1.6 для текста, 1.05–1.25 для заголовков (точнее — по таблице в разделе 0).
- Строка 45–75 символов (`max-width: 65ch`).
- Трекинг: заголовки −0.01…−0.03em; капс +0.05…+0.1em.
- 1–2 гарнитуры, 2–3 веса. Проверь кириллицу, казахские буквы и ₸.
- Числа в таблицах — `tabular-nums`, по правому краю; форматы — через `Intl`.
- Заголовки — `clamp()`, текст — в `rem` (зум 200% не ломается).

## 5. Сетка и адаптив

- 4 / 8 / 12 колонок (моб. / планшет / деск.), гаттер 16 / 16–24 / 24–32px, контейнер 1120–1280px.
- Брейкпоинты по контенту. M3: < 600 / 600–839 / 840–1199 / 1200–1599 / ≥ 1600 dp.
- Container queries для переиспользуемых компонентов.
- Навигация: таб-бар (compact) → rail (medium) → сайдбар (expanded).
- Логические свойства (`margin-inline-start`) для RTL; `env(safe-area-inset-*)`, `100dvh`; без горизонтального скролла на 320px.

## 6. Паттерны и состояния

- **Навигация:** таб-бар 3–5 пунктов с подписями; сайдбар для 5+ разделов; крошки от 3 уровней; гамбургер только для второстепенного (скрытую навигацию используют на треть–вдвое реже).
- **Цели нажатия:** 44×44 pt (iOS, минимум 28) / 48×48 dp (Android) / ≥ 24×24 CSS px (WCAG 2.2).
- **Формы:** одна колонка; лейбл над полем всегда; плейсхолдер — только пример; правильный `type`/`inputmode`/`autocomplete`; маски; ошибка после ухода с поля, рядом, текстом и иконкой, с решением; сводка ошибок короткой формы — над кнопкой отправки, длинной — вверху; данные не стираются; длинные формы — шагами.
- **5 состояний экрана:** идеальное, пустое (что будет + как получить + кнопка), загрузка (скелетон для знакомых раскладок, спиннер в кнопке с сохранением ширины), ошибка (что делать), крайние данные.
- **Подтверждения** только для необратимого; для остального — Undo 5–10 с. Кнопки — исходы («Удалить проект» / «Оставить»), фокус на безопасном.
- **Тосты** только для пассивных сообщений; ошибки и действия — не в тостах; `role="status"`.
- **Модалки:** Esc, крестик ≥ 44px, фокус внутрь и обратно; на мобильных — bottom sheet.

## 6a. Где ставить кнопки

- **Форма:** главная — в конце, по левому краю полей (путь к завершению, Wroblewski); вторичные слабее и часто не нужны; «Сбросить» не ставят; подписи над полями; не блокируй отправку молча — сводка ошибок над кнопкой.
- **Диалог:** справа внизу. macOS, iOS, Material, GNOME: «Отмена · **Главная**» (главная крайняя справа); Windows: «**Главная** · Отмена». В вебе выбери один порядок на весь продукт. Подписи — глаголы из заголовка («Удалить»), не «Да/Нет». Разрушительное красное только в подтверждении, фокус по умолчанию на «Отмена», Esc = отмена; третье действие отделено слева.
- **Мобильный:** главное действие внизу во всю ширину или в липком футере, ≥ 48 + safe area; важное и опасное не в верхнем левом углу; разрушительное не рядом с частым.
- **Мастер:** «Назад» слева и слабее, «Далее» справа; на последнем шаге — результат («Оформить заказ»).
- **Страница и таблица:** действия справа от заголовка, главная крайняя; в строке таблицы — справа, 1–2 иконки с `aria-label`, остальное в меню; массовые действия над таблицей со счётчиком.
- **Лендинг:** CTA под заголовком героя + максимум одна вторичная; повтор после ключевых секций; одна формулировка CTA на страницу.
- **Группы:** зазор 8–12 внутри, ≥ 24 между группами; одна Primary на группу.

## 7. Анимация

- 100 мс — микро; 150–250 мс — меню, тултипы; 200–300 мс — модалки, экраны; ≤ 400 мс — крупное; > 500 мс — затянуто. Выход короче входа.
- Вход — ease-out, выход — ease-in, перемещение — standard `cubic-bezier(0.2, 0, 0, 1)`.
- Только `transform` и `opacity`.
- `prefers-reduced-motion: reduce` → fade вместо движения, без параллакса и автопрокрутки; ≤ 3 вспышек в секунду; автодвижение > 5 с — с паузой.

## 7a. Эффекты и микро-анимации

- **Hover-анимация — только по просьбе пользователя.** При наведении меняются цвет, фон, рамка, толщина подчёркивания (≤ 150 мс). Без подъёма карточек, сдвига, масштаба, наклона, магнита, бликов по наведению.
- **Движение — обязательный слой, а не украшение.** Минимум на каждой странице: 1) каскадный вход (шапка → заголовок → блоки; 400 мс на элемент, сдвиг 16 px, шаг 50 мс, ≤ 8 шагов, всего ≤ 800 мс, через `animation … both`, чтобы без JS всё было видно); 2) отклик у всего интерактивного: при наведении — только цвет/фон (без движения), при нажатии — `scale(.97)`; 3) анимированные смены состояний (вкладки, фильтры, аккордеоны, модалки, тема — View Transitions с круговым раскрытием); 4) анимированные данные (FLIP при сортировке/фильтре 380 мс, счёт чисел 900 мс, прорисовка полос и точек графиков 700 мс со сдвигом 35 мс); 5) отклик на асинхронность; 6) появление секций при скролле на длинных страницах. Уровни: сдержанный (рабочие инструменты), продуктовый (по умолчанию), выразительный (лендинги, игры).
- **Правила:** у эффекта есть цель (статус, отклик, связь, внимание); частое действие — без анимации; отклик ≤ 100 мс; только `transform`/`opacity`; переключаемые состояния — `transition` (прерываются), разовые — keyframes/WAAPI; появление со `scale(.95–.97)`, не с нуля, из точки-источника; выход короче входа; при reduced motion — заменить движение фейдом, смысл (цвет, текст, `aria-live`) оставить; ничего бесконечного дольше 5 с; ≤ 3 вспышек/с.
- **Если «ничего не анимируется»:** почти всегда в системе включено «уменьшить движение» (`prefers-reduced-motion: reduce`, частая настройка корпоративных Windows). Дай на сайте режим анимаций «как в системе / включены / уменьшены» через `<html data-motion="full|reduce">`; на витринах показывай плашку «Анимации приглушены настройкой системы · Показать анимации».
- **Тряска поля:** только при отклонённом действии (пароль, PIN), всегда вместе с рамкой, иконкой и текстом; 360 мс, 8 → 6 → 4 → 2 px, 1 раз:
  `el.animate([{transform:'translateX(0)'},{transform:'translateX(-8px)'},{transform:'translateX(6px)'},{transform:'translateX(-4px)'},{transform:'translateX(2px)'},{transform:'translateX(0)'}],{duration:360,easing:'ease-out'})`
- **Быстрые параметры:** нажатие `scale(.97)` 120 мс · успех действия: сама кнопка заливается цветом успеха (200 мс) и рисует галочку вместо текста (280 мс), ширина не меняется, без отдельной надписи рядом · кнопка-загрузка: спиннер внутри, ширина фиксирована, `aria-busy` · модалка 200 мс, `scale .96 → 1`, `@starting-style` · тост ≈ 4 с, только пассивные сообщения · аккордеон `grid-template-rows 0fr → 1fr` 250 мс · вкладки: один индикатор `translateX + scaleX` · скелетон 2–10 с, мерцание 1.4 с · счётчик 350–1200 мс (суммы для сверки не анимировать) · каскад списка 200–300 мс, шаг 40 мс, ≤ 8 элементов · новое уведомление: колокольчик качается от верхней точки 800 мс (16° → −14° → 10° → −7° → 4° → 0), бейдж «поп» 450 мс + 3 кольца, число в `aria-live` · пульс бейджа 3 × 600 мс · блик 1–2 раза · конфетти только для редкого праздника · параллакс и магнитные кнопки — не в рабочем UI.
- **Игры:** тряска по «травме» (trauma², плавный шум, затухание ~0.5–1.4/с, HUD не трясти, ползунок 0–100%) · хитстоп 2–4 / 5–8 / 10–15 кадров по силе, ввод буферизуется · белая вспышка 1–3 кадра · цифры урона: поп 1.3 → 1, подъём и фейд ~0.9 с, крит формой и размером · HP с «призраком»: основная сразу, призрак через 300–600 мс · частицы 6–15 по 150–400 мс, пул · награды: нарастание → вспышка → предметы по очереди, редкий последним, всегда «открыть всё».

## 8. Фото и визуал (сайты)

- **Арт-дирекшн:** мудборд → 3–5 правил; единый свет, цветокоррекция, ракурс; реальные люди и продукт вместо стока; взгляд на заголовок или CTA; один тип визуала на страницу.
- **Текст на фото:** контраст по худшему участку и для всех фото в слоте. Порядок: негативное пространство → градиентный скрим под текстом (затемнение 40–60%) → text-shadow → стеклянная подложка → плашка. Фоновый цвет-фолбэк.
- **Слияние с UI:** брендовый оверлей или дуотон для разнородных фото; `mix-blend-mode` + `isolation: isolate`; растворение через `mask-image`; вырезки, выходящие за карточку, с контактной тенью; те же радиусы и тени, что у карточек; зерно 3–8%.
- **Кадр:** 2–3 соотношения (16:9, 3:2/4:3, 1:1, 4:5); `object-fit: cover` + `object-position`; лица в центральной зоне; отдельный мобильный кроп через `<picture>`.
- **Иконки:** один набор, сетка 24, одна толщина обводки, один стиль; подпись, если смысл не общепринят.
- **Эмодзи запрещены** — в кнопках, заголовках, пустых состояниях, слотах, тостах; и символы, которые рисуются как эмодзи (★ ✓ ✕ ⚠ ⚡ ❤ ☰ ⋯). Иконку скачай из открытого набора того же стиля (Lucide ISC, Tabler MIT, Phosphor MIT, Material Symbols Apache 2.0; игры — game-icons.net CC BY 3.0, Kenney CC0; `npm i lucide-static`) или нарисуй SVG: viewBox 24, обводка 2, `stroke="currentColor"`, round caps/joins, без заливки. Исключение — эмодзи в пользовательском контенте.
- **Производительность:** LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1. Герой — `<img>` с `fetchpriority="high"`, без lazy; lazy только ниже сгиба; `width`/`height` у всех медиа; AVIF q≈60 / WebP q≈80; герой ≤ ~400 КБ; `srcset` + `sizes`.
- **Видео-фон:** `autoplay muted loop playsinline poster`, < 10 с, < 5 МБ, кнопка паузы, постер при reduced motion.
- **Мета:** OG 1200×630; favicon.ico 32, icon.svg, apple-touch-icon 180, 192/512 + maskable.
- **Alt:** смысл в контексте; декоративное — `alt=""`; в кнопке — действие.

## 9. Лендинг

- Структура: герой → социальное доказательство → выгоды (3–4) → как работает → кейсы с реальными людьми → тарифы/FAQ → финальный CTA.
- Герой: H1 6–12 слов о пользе, 1 главный + 1 вторичный CTA, всё видно на 375×667.
- CTA — результат действия + снятие страха («Без карты»).
- Не шаблонно: одна смелая идея, свои фото, реальные данные; без набора «фиолетовый градиент + стекло + 3D-блоб + карточки по три».

## 10. Доступность (WCAG 2.2 AA)

- Видимый фокус (`:focus-visible`, 2–3px, ≥ 3:1), не перекрыт липким хедером (2.4.11); skip link; порядок фокуса = визуальный.
- Нативные элементы: `button` — действие, `a` — переход, `label` — поле; ARIA только если нативного нет; у иконочных кнопок есть имя.
- Альтернатива перетаскиванию (2.5.7); без когнитивных тестов и запрета вставки при входе (3.3.8); не просить ввести данные повторно (3.3.7); помощь на одном месте (3.2.6).
- Зум 200%, reflow на 320px, системный размер шрифта (Dynamic Type), интервалы текста 1.4.12.
- Тултипы закрываются Esc и не исчезают при наведении на них.

## 11. Тексты и локализация

- Кнопки — глагол + объект; ссылки конкретные; обычный регистр; одно слово — одно действие.
- Ошибка = что случилось + как исправить; для денег — списаны ли средства. Без жаргона, обвинений и юмора.
- Подтверждение называет объект и последствие.
- Короткие строки при переводе растут на 200–300%, длинные ~на 30% — не фиксируй ширину. Не склеивай строки; плюралы (one/few/many/other); даты, числа, валюты через `Intl`; RTL — логические свойства и зеркальные стрелки.

## 12. Дизайн-система

- Токены: примитивные → семантические → компонентные (формат W3C DTCG 2025.10). Компоненты ссылаются только на семантические.
- Минимум: neutral 50–950, primary 50–900, semantic × 3 роли, 2 темы; шрифтовые стили; отступы; 3–4 радиуса; 3 тени; длительности и кривые; z-index.
- Состояния каждого компонента: default, hover, focus, active, selected, disabled (с объяснением), loading, error, read-only.

## 13. Данные и доверие

- Графики: столбцы — сравнение (от нуля!), линии — тренд, scatter — связь; круговые — только 2–3 части; палитра Okabe–Ito; подписи у линий; заголовок = вывод; KPI всегда со сравнением.
- Финансы: итог (сумма, комиссия, получатель) перед подтверждением; ясные статусы операции; маскирование номеров.
- Тёмные паттерны запрещены (EU DSA ст. 25): отказ = согласие по лёгкости; без предвыбранных галочек, фейковой срочности, confirmshaming, скрытых платежей.
- ИИ-функции: «Стоп» во время генерации, перегенерировать/редактировать/копировать, уверенность категориями, маркировка ИИ-контента.

## 14. Игры

- **Типы UI:** диегетический (в мире, погружение, медленно читается), недиегетический (HUD, скорость), пространственный (маркеры в сцене), мета (эффекты на «камере»). Решай на старте.
- **HUD:** приоритет — выживание → цели → прогресс; контекстный (появился при изменении, погас), критичное не прячется; по краям, центр свободен; контраст против самого светлого и тёмного участка фона (4.5:1 / 3:1); обводка, тень, подложка; скрытие и масштаб HUD в настройках.
- **Safe area ТВ:** title-safe 90% (1728×972 при 1080p), action-safe 95% (1824×1026); ultrawide — HUD в зоне 16:9 или слайдер.
- **Текст (XAG 101):** консоль 1080p ≥ 26 px, 4K ≥ 52; ПК 1080p ≥ 18; Steam Deck ≥ 9 (реком. 12); масштаб до 200%.
- **Геймпад:** весь UI без мыши; фокус всегда виден; логичный порядок; LB/RB — вкладки; «Назад» везде; глифы по активному устройству, мгновенная смена; подтверждение по позиции кнопки платформы (Xbox A снизу, Nintendo A справа, PS × снизу); удаление — удержание с прогрессом или диалог с безопасным фокусом; системная экранная клавиатура.
- **Game feel:** многослойный отклик (визуал + звук + вибрация); hitstop 2–4 / 5–8 / 10–15 кадров при 60 fps для лёгкого/среднего/тяжёлого удара (в файтингах дольше, финал до 20); тряска по модели trauma с затуханием и гладким шумом, только камера рендера; coyote time ~5 кадров; буфер ввода ~100 мс; anticipation и squash & stretch. Всё «сочное» — отключаемо.
- **Онбординг (Hodent):** учить действием, по одной механике, контекстные подсказки, перечитываемые, не посреди боя.
- **Меню и настройки:** «Продолжить» первым; пропуск логотипов; пауза при потере фокуса; пресеты графики с превью и автооткатом; громкость по каналам; переназначение всех кнопок; инверсия по осям; чувствительность ±50%; иконка автосохранения.
- **Доступность (GAG, XAG):** субтитры ≥ 46 px при 1080p, ≤ 40 знаков, ≤ 2 строк, подложка 0–100%, имя говорящего, подписи звуков; цвет + форма; hold ↔ toggle; уровни сложности и замедление; укачивание — FOV-слайдер, отключение тряски, blur, покачивания; ≤ 3 вспышек в секунду.
- **Локализация:** закладывай до 2× длины для коротких строк; текст не в текстурах; fallback-шрифты.
- **Мобильные игры:** касания ≥ 15 мм, срабатывание по отпусканию, двигаемые контролы, важное в зонах больших пальцев. F2P без тёмных паттернов.
