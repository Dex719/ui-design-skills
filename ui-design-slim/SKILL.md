# UI/UX-дизайн: slim

Сжатая версия скилла `ui-design` (WCAG 2.2, Material 3, Apple HIG, NN/g, Xbox Accessibility Guidelines). Ставь один из двух скиллов, не оба.

## Процесс

1. Контекст: продукт, платформа, главная задача экрана, **одно** главное действие, аудитория.
2. **Система до экранов:** бриф в 3 словах + одно «не» → оси характера → параметры, у каждого записана причина. Для нового продукта — 2–3 варианта рядом на одной странице, различающиеся минимум по 3 осям; после выбора — только его токены. Спросить некого — выбери сам и напиши почему.
3. Порядок: контент → иерархия → сетка и отступы → типографика → цвет → изображения → движение.
4. Все состояния: идеальное, пустое, загрузка, ошибка, офлайн, крайние данные, фокус.
5. Чек-лист в конце — перед сдачей.

## 0. Система из брифа

| Ось | Что двигает |
|---|---|
| Энергия: спокойно ↔ громко | Хрома 0.05 → 0.20, шкала ×1.2 → ×1.5, вес заголовка 500 → 800, движение |
| Формальность: строго ↔ дружелюбно | Радиус 0–4 → таблетка; гротеск/антиква → округлый шрифт |
| Плотность: воздух ↔ данные | База 18 → 14, шаг отступов, контрол 52 → 32 |
| Температура: холодно ↔ тепло | Нейтрали slate → sand, тон акцента |
| Вес: легко ↔ плакатно | Веса, рамки 0–1 → 2–3, тени мягкие → жёсткие |

- **База шрифта** по расстоянию и аудитории: данные 13–14 · приложение 16 · iOS 17 · чтение и 55+ 18–20 · киоск 20–24 · ТВ 24–28. Минимум 12. Поле ввода в iOS ≥ 16.
- **Шкала:** ×1.2 мобильный и плотно · ×1.25 приложение · ×1.333 медиа · ×1.5 промо (только десктоп, на мобильном — `clamp()`). 5–7 уровней, дальше — весом и цветом. H1 ≥ 1.6× текста.
- **Межстрочный:** текст 1.5–1.6 · 22–32 px → 1.25–1.35 · 36–56 → 1.1–1.2 · 64+ → 0.95–1.05. Трекинг крупных −0.01…−0.03em, капс +0.05…+0.1em. Строка 45–75 символов (`max-width: 65ch`).
- **Гарнитура:** 1–2, 2–3 веса. Нейтрально — Onest, Manrope, Golos Text, Inter; редакционно — PT Serif, Lora + гротеск; мягко — Nunito, Rubik. Проверь кириллицу, казахские буквы (ә ғ қ ң ө ұ ү һ і) и ₸.
- **Отступы:** шкала 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96, внутри группы меньше, чем между группами; по уровням ×1.5–2 (поле↔подпись 4–8 · поля 12–16 · группы 24–32 · секции 64–128).
- **Контролы — из брифа:** высоту выводи из плотности, устройства и аудитории (ориентиры: 32–36 плотно · 40 десктоп · 44 iOS · 48 Android · 52–56 для 55+ и киосков); верх диапазона — не выбор по умолчанию; в ряду одна высота.
- **Радиус — из языка форм,** значение от высоты h: строго 0–2 · нейтрально h/6 · мягко h/4 · таблетка h/2; вложенный = внешний − отступ; 3–4 значения на систему.
- **Вид поля — часть характера:** контур (длинные формы, данные) · заливка с линией снизу (мобильные, короткие формы) · подчёркивание (мало полей, премиум) · таблетка (поиск, промо). Граница поля ≥ 3:1 с фоном.
- **Цвет за 5 шагов:** 1) нейтрали — 60–80% экрана, и это решение: фон (почти белый с оттенком, чистый белый, кремовый, холодный, тинт акцента, тёмный), сила оттенка и температура — не одна готовая шкала на все продукты; 2) тон акцента из смысла и в стороне от конкурентов; никакой тон не по привычке — ни синий и индиго, ни тёмная приглушённая слива; 3) хрома из энергии: 0.04–0.08 тихо · 0.09–0.13 уверенно · 0.14–0.18 ярко; приглушённость не безопаснее яркости, яркий акцент с тёмным текстом — полноценный вариант; 4) светлота: акцент с белым текстом L ≤ ~0.55 (зелёные и оранжевые ≤ ~0.50), яркие жёлтый/лайм — только с тёмным текстом; 5) контраст в обеих темах и проверка в оттенках серого. Акцент ≤ 10% экрана, не совпадает с «успехом».
- **Запиши систему:** цвет, типографика, отступы, формы, глубина, движение — каждое с `why`, плюс одна фирменная деталь (`signature`) — элемент бренда на всех экранах, а не служебная метка или значок.

## 1. Восприятие и законы

- **Не заставляй думать:** кликабельное выглядит кликабельным; люди сканируют и жмут первое разумное.
- **Отклик:** 0,1 с — мгновенно · 0,4 с — порог Доэрти · > 1 с — индикатор · > 10 с — прогресс и отмена. Частые обратимые действия — оптимистичный UI.
- **Фиттс** — важное крупнее и ближе, опасное дальше от безопасного. **Хик** — меньше вариантов за раз. **Якоб** — стандартные паттерны. **Теслер** — сложность на систему (умолчания, автозаполнение). Группы по 3–5.
- **Нильсен:** статус системы, язык пользователя, Undo, единообразие, предотвращение ошибок, узнавание вместо вспоминания, понятные ошибки.

## 2. Иерархия и цвет

- Иерархия **весом и цветом**, а не только размером; ослабляй второстепенное. Значение крупно, лейбл мелко.
- Одна Primary (заливка) на экран; Secondary — контур; Tertiary — текст; разрушительное красное только в подтверждении.
- Рамки в последнюю очередь — разделяй фоном и отступом. Тест прищуривания: видны заголовок, главное действие, 2–4 блока.
- **Контраст WCAG 2.2 AA:** текст 4.5:1 · крупный (≥ 24 px или ≥ 18.66 px bold) и элементы UI 3:1 · AAA 7:1. Текст на фото — по худшему участку.
- Смысл не только цветом: ошибка = цвет + иконка + текст.
- **Тёмная тема:** по системной настройке, не инверсия; поверхности тёмные с оттенком (≈ `#111113` / `#18191b`), выше = светлее, вместо теней; акцент светлее и мягче; текст не чисто белый (≈ `#edeef0`); контраст проверяй отдельно.
- Всё из токенов: примитивные → семантические (`text-danger`, не `red-text`) → компонентные; компоненты ссылаются только на семантические.

## 3. Сетка и адаптив

- 4 / 8 / 12 колонок, гаттер 16 / 24 / 32, контейнер 1120–1280. Брейкпоинты по контенту (M3: 600 / 840 / 1200 / 1600).
- Container queries для компонентов; логические свойства (`margin-inline`) для RTL; `env(safe-area-inset-*)`, `100dvh`; нет горизонтального скролла на 320 px; зум 200%.
- Навигация: таб-бар 3–5 пунктов с подписями → rail → сайдбар; гамбургер только для второстепенного.

## 4. Паттерны, формы, кнопки

- **Цели нажатия:** 44×44 pt (iOS) · 48×48 dp (Android) · ≥ 24×24 CSS px (WCAG 2.5.8).
- **Формы:** одна колонка; лейбл над полем всегда; формат — визуально (пример и маска в поле), а не текстом под ним; визуально — только формат, не условия и правила; правильные `type`, `inputmode`, `autocomplete` (по владельцу данных: данные другого человека — получателя, контакта — `off`, иначе подставятся данные самого пользователя); ошибка после ухода с поля, рядом, по единому словарю типов (одна формулировка на тип — «Обязательное поле», «Неверный ‹что›» — а не фраза под каждую причину); данные не стираются; сводка ошибок над кнопкой отправки.
- **Состояния экрана:** пустое (что будет + как получить + кнопка) · загрузка (скелетон для знакомых раскладок, спиннер в кнопке без смены ширины) · ошибка (что делать) · офлайн · крайние данные.
- **Подтверждение** только для необратимого, иначе Undo 5–10 с. Кнопки называют исход («Удалить проект» / «Оставить»), фокус на безопасном.
- **Тосты** только для пассивных сообщений, ≥ 4–6 с, с кнопкой закрытия, `role="status"`. **Модалки:** Esc, фокус внутрь и обратно; на мобильном — bottom sheet.
- **Где кнопки:** форма — главная в конце, по левому краю полей · диалог — справа, порядок единый во всём продукте · мобильный — главное внизу во всю ширину + safe area · мастер — «Назад» слева и слабее · таблица — массовые действия над ней со счётчиком · лендинг — CTA под заголовком героя + одна вторичная. Разрушительное не по Enter и не рядом с частым.

## 5. Движение

- Длительности: 100 мс микро · 150–250 мс меню · 200–300 мс модалки и экраны · ≤ 400 мс крупное · выход короче входа. Вход ease-out, выход ease-in. Только `transform`/`opacity`.
- **Сначала уровень — по цене ошибки и частоте действия.** **Минимальный** — высокая цена ошибки (деньги, здоровье, права, документы; например, банк, госуслуги, медицина) и любой шаг оплаты: только отклик нажатия, смена состояний контролов, загрузка в кнопке, появление модалки или шторки, одна галочка успеха; без каскадного входа, счёта денежных сумм, тряски полей, бликов, пульсаций и праздников. **Сдержанный** — рабочие инструменты: + фейд входа, FLIP при сортировке. **Продуктовый** — потребительские приложения: + каскадный вход (400 мс, шаг 50 мс, ≤ 8 шагов), счёт чисел (не денег для сверки), прорисовка графиков. **Выразительный** — лендинги и игры.
- **Hover — только цвет, фон, рамка, подчёркивание** (≤ 150 мс). Подъём, сдвиг, масштаб, наклон, «магнит», блики по наведению — только по просьбе пользователя.
- У эффекта есть цель; частое действие — без анимации; тряска поля — не в официальных продуктах и только вместе с текстом ошибки (360 мс, 8 → 6 → 4 → 2 px); каскад списка 200–300 мс, шаг 40 мс, ≤ 8 элементов; конфетти — только для редкого праздника; ничего бесконечного дольше 5 с; ≤ 3 вспышек в секунду.
- `prefers-reduced-motion: reduce` → фейд вместо движения, смысл (цвет, текст, `aria-live`) остаётся. Служебные элементы демо и витрин (плашки о настройках, панели состояний) в продукт не переносятся: системные настройки пользователя уважают молча.

## 6. Визуал и медиа

- **Эмодзи запрещены** — в кнопках, заголовках, пустых состояниях, тостах; и символы, которые рисуются как эмодзи (★ ✓ ✕ ⚠ ⚡ ❤ ☰ ⋯). Иконки — SVG из одного набора (Lucide, Tabler, Phosphor, Material Symbols): viewBox 24, обводка 2, `currentColor`.
- **Фото:** один стиль света и цвета; текст на фото — через градиентный скрим 40–60%; одни радиусы и тени с карточками; 2–3 пропорции (16:9, 4:3, 1:1, 4:5).
- **Скорость:** LCP ≤ 2,5 с · INP ≤ 200 мс · CLS ≤ 0,1. Герой — `<img fetchpriority="high">` без lazy; `width`/`height` у всех медиа; AVIF/WebP; `srcset` + `sizes`. OG 1200×630.
- **Alt** — смысл в контексте; декоративное — `alt=""`.
- **Лендинг:** герой (H1 о пользе, 1 главный + 1 вторичный CTA, видно на 375×667) → доказательства → выгоды → как работает → тарифы/FAQ → финальный CTA. Одна смелая идея вместо «градиент + стекло + блобы».

## 7. Доступность, тексты, доверие

- Видимый фокус (`:focus-visible`, 2–3 px, ≥ 3:1), не перекрыт липкой шапкой; skip link; порядок = визуальный. Нативные `button`/`a`/`label`; ARIA только без нативного аналога; у иконочных кнопок есть имя.
- WCAG 2.2: альтернатива перетаскиванию (2.5.7), без запрета вставки и когнитивных тестов при входе (3.3.8), не просить ввести данные повторно (3.3.7).
- **Тексты:** кнопка = глагол + объект («Оплатить 12 500 ₸», не «ОК»); ошибки — единый короткий словарь по типам: одна формулировка-шаблон на тип, подходит к любой причине; как исправить — только если это нельзя понять из состояния; без «Ошибка:», восклицаний и советов очевидного. Меньше текста: не пересказывай словами то, что видно по структуре и состоянию экрана — инструкции к интерфейсу, объяснения состояний, формат словами, пояснения к понятным вариантам. Условия из брифа (кому доступно, лимиты, правила) — поведение: проверка и ошибка в момент нарушения, а не постоянные метки и плашки. Не выдумывай факты о продукте (сроки, проверки, гарантии): только из брифа или данных, иначе — явная заглушка.
- **Локализация:** перевод удлиняет короткие строки до 2–3 раз — не фиксируй ширину; не склеивай строки; плюралы (ru: one/few/many/other, kk: one/other); числа, даты, валюты через `Intl` (`ru-KZ`, `kk-KZ`), неразрывный пробел перед ₸; `lang` у фрагментов на другом языке; переключатель языка словами («Қаз / Рус»), не флагами.
- **Данные:** столбцы от нуля, линии — тренд, круговые — 2–3 части; заголовок графика = вывод; KPI со сравнением; цифры `tabular-nums` по правому краю.
- **Без тёмных паттернов:** отказ так же лёгок, как согласие; без предвыбранных галочек, фейковых таймеров, скрытых платежей. Финансы — итог (сумма, комиссия, получатель) перед подтверждением.
- **ИИ-функции:** «Стоп» во время генерации, перегенерировать/править/копировать, источники, маркировка ИИ-контента.

## 8. Игровой UI — коротко

- HUD по краям, центр свободен; приоритет: выживание → цели → прогресс; контраст против самого светлого и тёмного фона; масштаб и скрытие HUD в настройках.
- ТВ: title-safe 90% (1728×972 при 1080p), action-safe 95%. Текст: консоль 1080p ≥ 26 px, ПК ≥ 18 px; субтитры ≥ 46 px, ≤ 40 знаков, ≤ 2 строки.
- Геймпад: весь UI без мыши, фокус всегда виден, «Назад» везде, глифы по активному устройству.
- Game feel: хитстоп 2–4 / 5–8 / 10–15 кадров при 60 fps, тряска по «травме» только камеры; всё «сочное» отключаемо; ≤ 3 вспышек в секунду.

## Чек-лист перед сдачей

- [ ] Главная задача и одно главное действие очевидны за 5 секунд; тест прищуривания пройден.
- [ ] Система выведена из брифа, у каждого значения есть причина; всё из токенов, обе темы.
- [ ] Внутренние отступы < внешних, шкала 4/8, общие линии выравнивания.
- [ ] Контраст ≥ 4.5:1 / 3:1 в обеих темах и на фото; смысл не только цветом.
- [ ] Тема по умолчанию следует системной (`prefers-color-scheme`); ручной переключатель только переопределяет её.
- [ ] Цели нажатия ≥ 44 pt / 48 dp / 24 px; одна Primary-кнопка; кнопки на своих местах.
- [ ] Все состояния экрана и компонентов (hover, focus, active, disabled, loading, error).
- [ ] Клавиатура и геймпад: фокус виден, порядок логичен, ловушек нет.
- [ ] Тексты: глаголы на кнопках; ошибки короткие и по факту; подсказки — визуальные; нет лишних строк; длинные переводы не ломают раскладку.
- [ ] Адаптив: 320, 375, планшет, 1440, зум 200%.
- [ ] Движения ровно столько, сколько позволяет уровень (чем выше цена ошибки, тем меньше); hover без движения; reduced motion уважается.
- [ ] Эмодзи нет; иконки из одного набора; единые радиусы и тени.
- [ ] Нет тёмных паттернов.
